# IPL 2022 Capstone Project

A data analysis project based on the **Indian Premier League (IPL) 2022** season.
The project explores team performance, toss decisions, player performance, batting, bowling, and match outcomes using Python data-science libraries.

## Project Overview

The analysis covers:

*  Team match wins
*  Toss decisions and their impact
*  Toss winner vs. match winner
*  Runs vs. wickets victories
*  Player of the Match awards
*  Top run scorers and highest scores
*  Best bowling performances
*  Venue analysis
*  Highest winning margins

## Technologies Used

* **Python**
* **Pandas** – Data analysis
* **NumPy** – Numerical operations
* **Matplotlib** – Data visualization
* **Seaborn** – Statistical visualization

## Project Files

* `IPL_Capstone_Project.ipynb` — Main analysis notebook
* `IPL.csv` — IPL 2022 dataset

## Key Learning Outcomes

This project demonstrates practical skills in:

* Data cleaning and exploration
* DataFrame manipulation with Pandas
* Numerical analysis with NumPy
* Data visualization
* Extracting insights from real-world datasets
